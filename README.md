# Simple Payment System

Учебная симуляция платёжной системы на Go. Проект демонстрирует работу с разными способами оплаты, хранение информации о транзакциях и отмену операций.

> **Статус:** WIP — проект находится в разработке и предназначен для обучения и экспериментов.

## Возможности

- проведение платежей с описанием операции и суммой;
- получение уникального идентификатора платежа;
- отмена ранее проведённой операции;
- получение информации о конкретном платеже;
- получение списка всех платежей;
- поддержка нескольких способов оплаты через единый интерфейс `PaymentMethod`.

## Доступные способы оплаты

В каталоге `payments/methods` реализованы следующие методы:

- банковская карта — `methods.NewBank()`;
- PayPal — `methods.NewPayPal()`;
- криптовалюта — `methods.NewCrypto()`;
- бонусы — `methods.NewBonus()`.

Сейчас методы оплаты являются симуляциями: они выводят информацию в консоль и генерируют случайный ID операции без подключения к реальным платёжным сервисам.

## Запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/arccthecoder/Simple-payment-system.git
cd Simple-payment-system
```

Запустите пример:

```bash
go run .
```

Программа проведёт несколько тестовых платежей, отменит одну операцию и выведет информацию о транзакциях в консоль.

## Пример использования

```go
package main

import (
    payment "payment/payments"
    "payment/payments/methods"
)

func main() {
    method := methods.NewBank()
    paymentModule := payment.NewPaymentModule(method)

    paymentID := paymentModule.Pay("Покупка товара", 100)
    paymentModule.Cancel(paymentID)

    info := paymentModule.Info(paymentID)
    allPayments := paymentModule.AllInfo()

    _ = info
    _ = allPayments
}
```

## Добавление нового способа оплаты

Новый способ оплаты должен реализовать интерфейс:

```go
type PaymentMethod interface {
    Pay(usd int) int
    Cancel(id int)
}
```

После этого его можно передать в конструктор `NewPaymentModule`:

```go
method := methods.NewBank()
paymentModule := payment.NewPaymentModule(method)
```

## API модуля

### `NewPaymentModule(paymentMethod PaymentMethod)`

Создаёт новый экземпляр платёжного модуля с выбранным способом оплаты.

### `Pay(description string, usd int) int`

Проводит платёж, сохраняет его описание и сумму, а затем возвращает ID операции.

### `Cancel(id int)`

Отменяет платёж по ID и помечает его как отменённый.

### `Info(id int) PaymentInfo`

Возвращает информацию о конкретной операции.

### `AllInfo() map[int]PaymentInfo`

Возвращает информацию обо всех операциях.

## Модель платежа

Каждая операция представлена структурой `PaymentInfo`:

```go
type PaymentInfo struct {
    Description string
    Usd         int
    Cancelled   bool
}
```
